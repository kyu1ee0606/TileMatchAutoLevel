## 6. 미검증·한계
- 배치 전체를 파이썬/C# 어느 쪽으로도 **실제로 돌려보지 않음**. 합계는 [기록] 생성 시간 + [실측] 단가(3레벨) + 호출 수 가정의 곱.
- 실측은 load 5.7~7.7(유휴 아님), 3레벨 표본, C# 은 CLI 냉시작(JIT 포함) — 상주 워커 배수(15~27×)와 IPC ~1 ms 는 **미측정 추정**.
- `generate()` 측정은 기본 GenerationParams — 생산 프론트가 넘기는 패턴·템플릿·유닛 조립·보스 경로는 미측정(1.7 s/회는 기록 역산값).
- 검증 루프의 측정 건수·재생성 후보 수는 기록에 직접 없음(`regen_attempts` 합과 코드 주석 비율로 추정). 각 세션 1라운드 측정 시각은 기록에 안 남음.
- `skill_v1` C# 일치는 24점/486판만. `/tune/auto` 내부 비용 구성은 코드 미독.
- 내보내기·업로드·IndexedDB 처리 시간은 미측정(수 분 추정).
- C# A* 이식 후 수치(1~3 min)는 근거 약한 추정.

# CHANGELOG 2026-07-03 — craft/stack 내부 타일 단색 뭉치 해소 + bake 폴백 수정 + sync

## 요약
상자(craft)/스택(stack) 컨테이너 내부 타일이 **동일 타입 3개 뭉치**로 배출되던 문제 해결.
내부 타일이 필드 일반 타일처럼 골고루 섞이도록 생성 단계에서 명시 다양화 bake.

## 1. bake t1 폴백 제거 (커밋 `4522f67`)
- **문제**: `bakeFullBoard`의 craft/stack inner 루프가 미해결 inner를 `raw || 't1'`로 폴백 →
  미해결 슬롯 전부 t1에 몰림 → per-type ÷3 위반(레벨 1223/1270/1378/1430/1440 t1만 위반).
- **수정**: inner 슬롯 하나라도 미해결이면 명시 bake 스킵 → `td[2]=[cnt]` 개수만 유지 →
  게임 런타임이 필드 일반 타일과 동일 재분배(÷3 보존). 게임 무변경.

## 2. 내부 타일 명시 다양화 (커밋 `31fa822`)
- **근본 원인**: 패턴 기반 프로덕션 레벨은 필드 타일 전부 명시(t0 없음) → 컨테이너 내부만 t0
  분배 대상. 게임 분배(DB_Level.ShuffleEmptyTiles)는 '같은타입 3개=1세트' 단위 배정 + 약한
  n-swap 셔플 → 내부 3슬롯이 **단색 확정**(예 craft 내부 t8_t8_t8). 결정적(운 아님).
- **수정** (`generator.py` `_diversify_container_inner_tiles`, `generate()` 마지막 단계):
  1. 필드 t0==0일 때만 발동(필드 t0 있으면 게임이 자연 혼합).
  2. 게임 분배 포트(`assign_t0_tiles`)로 내부 타입 확정(toAdd/key 게임 정합).
  3. 컨테이너 내 중복 슬롯 ↔ 필드 다른타입 일반타일 **라벨 스왑**(randSeed 시드, 결정적).
     순수 순열 → 전역 타입별 카운트 불변 → **÷3 완전 보존**.
  4. 명시 신포맷 `td[2]=[cnt,"tX_tY_.."]`(v1.10.382+, 게임 리터럴 스폰) 출고.
  5. 'key' 슬롯 고정(unlockTile 키는 t0 슬롯에만 스폰 가능).
- **적용 범위**: `generate()` 단일 관문 → 신규/순차검증 재생성/enhance/band-rework 전부.
- **검증**: 신고 레벨 t8_t8_t8→t8_t4_t6, 전역 ÷3/solver gate 통과, 봇 시뮬 파싱 일치,
  역생성 E2E diverse, 결정성/멀티 컨테이너/cnt=4 엣지 통과.
- **데이터**: 기존 배치 11~100 컨테이너 레벨 87개 라벨스왑 192회 수리(서버 v35).

## 3. 서버 배치 버전 비교 pull (커밋 `e133d7b`)
- **문제**: `pullAllToLocal`이 '로컬에 있으면 무조건 스킵' → 서버측/타 브라우저 수정이 현재
  브라우저에 반영 안 됨 + 리로드 후 stale 사본이 서버 최신본 덮어쓸 위험(수리본 미표시 원인).
- **수정** (`productionServerSync.ts` + `ProductionBatch.__server_version`): push/pull 시 서버
  버전 영속화, 서버 버전 > 로컬이면 자동 pull. 버전 동일 시 pull 0회(메모리 안전 유지).
  push base_version을 메모리→영속 순 폴백 → 리로드 후에도 409 충돌 감지.

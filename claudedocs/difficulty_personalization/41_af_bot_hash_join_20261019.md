## 중요한 보완 발견

### L501 이후에도 이미 측정된 결과가 존재

`cand_a1a2/bot_v24_rules_A2.json`에 10/16 측정된 11개 맵이 존재한다:
`505,507,521,531,537,551,558,566,568,577,578`.
저장 메타의 프로토콜은 theta4x128_v1, seed11M, 규칙 6개, 커밋 b741f6a3. `prep_ext.json`과 샤드 맵/조건을 대조해 모두 일치했다. 과거 35a 문서의 “미측정”은 당시 상태이며 현재 파일에는 결과가 있으므로 신규 측정이 필요하다고 단정하면 안 된다.

### L33은 실제 샤드 기준으로 재사용 가능

L33은 에디터 LIVE3와 달라 문서 40의 같은 에디터 맵 집계에서 제외했다. 하지만 저장된 봇 입력은 **실제 배포용 샤드 스냅샷**이며 Android 1.0.162/1.1.0, iOS 2.1.0 대응 맵 및 조건과 일치한다.
AF n=2,443(추가 90), 클리어율 81.74%. 해당 **샤드 맵 해시**로 연결할 수 있다. 에디터의 다른 L33 맵을 검증했다고 표시해서는 안 된다.

### L429·494·499: 파일명만 보고 규칙 전용으로 처리하면 안 됨

`bot_v2.4f_no_rules_only.json`의 이 세 레벨 행에 `bomb_beta`, `bomb_impulse` 등이 남아 있고, 실제 맵에도 폭탄이 있다(L494/499는 stack도 존재). `abl_rules_only_rows.json`에는 세 레벨의 재측정 행이 없다. 따라서 같은 프로토콜로 자동 합치지 않고 `protocol_review`로 보류했다.

- L429 n180, 76.11%; L494 n147, 71.43%; L499 n143, 78.32%.
- 별도 v2.3/v2.4 과거 결과는 있으나 현재 규칙 전용 결과와 동일하지 않다. 버전별 분리 분석은 가능해도 자동 혼합은 금지.
- 이것이 현재 활성 모델 오염을 입증한 것은 아니다. 실제 학습 편입 여부는 별도 확인 대상이다.

## 대조 방법과 한계

1. 저장 `bot_v21/prep.json`과 `bot_v24/prep.json` 내용·파일 SHA256 동일 확인.
2. 확장 `cand_a1a2/prep_ext.json`을 합쳐 입력 맵을 확보.
3. 버전별 Git 샤드를 복호하고 canonical 전체 SHA256(타입 포함) 비교. 구조만 같다는 이유로 일치 처리하지 않음.
4. `randSeed,useTileCount,unlockTile,shuffleTile,typeImbalance,autoCollectCount,timea,layer` 8개 조건도 별도 비교.
5. θ={0.55,0.65,0.85,1.0}, 각128판, 승수 범위, 버전, 추가 옵션 확인.
6. ablation 생성 코드가 영향 없는 레벨의 원행을 복사하는 방식임을 확인했다. 행 라벨에 잔존한 옵션은 해당 기믹 부재 또는 autoCollectCount=0을 정적으로 확인한 경우에만 비활성으로 판단. 영향 가능한 세 레벨은 보류.

**증거 한계**: 기존 결과 행 자체에 맵 해시/불변 실행 manifest가 없다. 저장 prep, 생성 코드, Git 샤드로 연결을 재구성한 것이며 실행 당시 입력의 암호학적 증명은 아니다. 앱 버전↔배포 커밋 대응도 문서 40과 같이 실제 배포 바이너리가 아닌 Git 근거 추정이다. 향후 측정 재개 시에는 map hash·조건 hash·봇 버전·seed protocol을 결과에 직접 저장하는 것이 필요하다.

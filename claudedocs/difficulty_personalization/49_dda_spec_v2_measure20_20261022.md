### 1-3. 지표·판정 기준 (숫자 고정)
- W = 맵의 3θ 합산 클리어율(150판). Δ = W_후보 − W_원본. 필드 평균 = 선정 3개 합산(450판).
- CI: 맵 W = Wilson 95%(z 1.96). Δ = Newcombe hybrid score 95%(독립 근사, CRN 짝 효과 무시 = 보수적).
- 후보 판정 (쉬움 easy/easy2 는 Δ>0, 어려움 hard/hard2 는 Δ<0 가 의도 방향)
  - **확인**: 방향 일치 AND Δ CI 가 0 제외
  - **방향일치(미확정)**: 방향 일치, CI 가 0 포함
  - **역방향경향**: 반대 방향, CI 0 포함 / **유의역방향**: 반대 방향, CI 0 제외 / **변화없음**: Δ=0 (불일치로 셈)
  - **평가불가**: W_원본 ≥ 0.95 → 쉬움 필드, W_원본 ≤ 0.05 → 어려움 필드 (따로 집계, 일치율 분모에서 제외)
- 역전: 기대 순서 W(easy2) ≥ W(easy) ≥ W(원본) ≥ W(hard) ≥ W(hard2)
  - 필드 평균 인접 쌍이 반대면 역전, Newcombe CI 0 제외면 유의 역전
  - 후보 단위: 단계가 다른 모든 쌍(원본 포함, 레벨당 170쌍) 중 쉬워야 할 쪽 W 가 더 작으면 역전, CI 0 제외면 유의 역전
- 선정 후보 **부적합**: (R1) 원본 대비 유의역방향, 또는 (R2) 인접 단계(원본 제외)의 기존 선정 3개 합산 W 와 비교해 유의 역전
- **재선별**: 필드의 선정 3개 중 부적합이 1개라도 있으면 필요. 새 선정 = 5개 중 부적합 제외 후 cand 순서 앞 3개(측정값 순 고르기 아님 — 150판 잡음에서 승자의 저주 방지). 3개 미만이면 필드 보류. 참고로 "W 극단 순 3개"를 골랐을 때 바뀌는 필드 수도 보고(채택 안 함).
- 관측 없는 PASS 금지: 150판이 다 모이지 않은 레벨은 "미측정"으로만 보고.
- 검정력: 150 대 150판, p≈0.5 에서 Δ CI 반폭 약 ±0.11. |Δ| 0.1 미만 차이는 "미확정"이 정상이다.

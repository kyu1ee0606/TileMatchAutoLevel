### G `grass_cover_blindness`
- "덮임"은 게임 규칙의 판정과 같은 것을 쓴다(`_is_blocked_by_upper` = CheckUpperTileExist).
- ON이면 덮인 풀은 플레이어 모델에서 빠진다.
  1. 턴 인지 추첨은 덮이지 않은 풀만 본다. 덮이지 않은 풀이 없으면 추첨하지 않는다(RNG 미소비).
  2. 인지에 걸린 풀 점수(감소 가점, 고립 감점, public plan)가 덮인 풀을 무시한다.
  3. 롤아웃 결정화 사본에서 덮인 풀의 효과를 지운다. 그래서 탐색이 덮인 풀 실패를 미리 보지 못한다.
- 덮이지 않은 풀은 기존의 숙련도별 인지 추첨을 그대로 쓴다(θ 의존, 고수도 확률 < 1). 이것이 "임계 밑으로 떨어뜨리는 선택의 위험 인지 = 숙련도별 확률"이다.
- 실제 게임 상태와 규칙 엔진은 그대로다(실패는 진짜 규칙으로 난다).

### C `bomb_count_awareness` — 폭탄별 인지, 한 번 인지하면 유지 (2026-10-27 사용자 보정 반영)
- 관찰: 사람은 매 턴 새로 판단하지 않는다. 한 번 인지한 폭탄은 계속 인지하고, 아직 인지하지 않은 폭탄은 카운트가 줄수록 인지하기 쉬워진다.
- **상태**: 판 상태에 폭탄별 인지 집합 `state._c_noticed`를 둔다. 판 시작 때 비운다.
- **최초 인지**:
  - 대상: 아직 인지하지 않은 노출 폭탄(덮이지 않고, 집히지 않고, 살아 있는 폭탄). 폭탄마다 1회 추첨한다.
  - 확률 p = 기존 인지 확률 식(α + β(θ−1), 노출 계수 포함)에서 계단형 γ·[c≤1]을 **γ/c**로 바꾼 것. c = 그 폭탄의 카운트.
  - c=1에서 기존 '임박' 값과 같고, c가 줄수록 엄격히 증가한다.
  - **새 상수 0개.**
- **유지**: 인지한 폭탄은 해제되거나 폭발해 `bomb_tiles`에서 빠질 때까지 계속 인지 상태다. 망각이 없다.
- **시점·경로**: 판 시작 때 1회, 그리고 매 수 후 `_process_move_effects` 끝(카운트 감소 후). 이 전이는 본판 루프와 탐색 롤아웃(`_v2_step`)이 공유한다.
- **전용 RNG**:
  - 판 시작 때 본판 RNG 상태를 복제해 별도 시드로 파생한다. 본판 RNG는 소비하지 않는다.
  - 롤아웃 사본(`_v2_copy_state`)은 인지 집합과 전용 RNG를 복제해 가져간다. 그래서 탐색이 실제 판의 전용 RNG를 앞당기지 않는다.
- **사용**:
  - 기존 폭탄 긴급도 항(`_bomb_urgency`)은 **인지한 폭탄만** 본다. 미인지 폭탄은 플레이어 모델에 없다.
  - 부모의 턴별 본판 RNG 폭탄 추첨은 그대로 일어난다(본판 RNG 소비 패턴 불변). 다만 더 이상 게이트로 쓰지 않는다.
- **관계**: 기존 실험 `bomb_threat_memory`(유지 확률 .55+.30·skill, 망각 있음)는 이 후보로 대체된다. 조합 셀은 없다.

### 6-3. 해석
- **G(덮인 풀 무지각)는 L152형 과소 실패를 거의 만들지 못한다.** 26의 trace 결론과 같다. 봇은 매치 수를 선호하고 함정 수가 드물어서, 숨겨도 그 수를 고르지 않는다.
  - 오히려 L184처럼 풀 실패가 이미 맞는 맵에서 과대가 되고, L189·154에서 클리어가 떨어져 gate에 실패했다.
  - 사람이 덮인 풀 옆을 고르는 이유(관찰)는 "모른다"만으로는 재현되지 않는다. 사람은 비매치 픽 선호나 풀 근처 선택 동기를 같이 갖는 것으로 보인다. 클릭 로그 없이 확정할 수 없다.
- **C(폭탄 인지 유지)는 폭탄 맵에서 클리어와 폭탄 실패 오차를 크게 줄인다.** 다른 맵 V에서도 재현된다. 대신 남은 실패가 일반 실패로 옮겨 TV가 나빠진다.
  - 일반 실패 과대는 폭탄과 무관한 독 관리 오차로 보인다(예: L328·346은 B부터 일반 실패 19~21%). 별도 과제다.
- **ALL(K1+P2+G+C)**:
  - craft·key가 함께 있는 폭탄 맵 L292·306에서 B 0.8~7%를 52~65%로 끌어올린다(P2·K1 효과).
  - 양 기믹 6맵 클리어 MAE는 9.0%p다.
  - 실패 분포 TV는 B보다 나쁘다.

### 6-4. 결정 필요 (사용자)
1. **C의 채택 여부.** 기계 판정은 미지지(TV)다. 그러나 클리어·폭탄 실패 오차는 크게 개선된다. TV 조건을 유지할지, 남은 일반 실패 과대를 먼저 다룰지 결정해야 한다.
2. **K1·K2·P2·C 조합 채택.** ALL은 판정 대상이 아니라 종합 추정이다. 채택하려면 새 PREREG(ALL vs B, 미사용 맵)가 필요하다.
3. **G는 기각을 제안한다.** 풀 과소 실패는 다른 메커니즘 가설이 필요하다. 사람의 비매치 픽 선호나 "풀 줄이려고 옆 집기" 동기 등이며, 클릭 로그(계측) 확보 후 검토한다.

> **주석 (2026-10-27, 문서 61 발견)**: 랜덤 배치 맵(randSeed 0) L292는 이 문서의 측정에서 **배치 1개(layout seed 1)**로만 측정했다. AF는 여러 랜덤 배치를 섞은 값이라 이 맵의 행은 배치 효과가 섞여 있다(예: L388은 배치 1개에서 θ1.0이 100%, 배치 32개에서는 73%). 판정을 사후에 바꾸지는 않는다. 다음 러너부터는 다중 배치로 측정한다(문서 62 §2).

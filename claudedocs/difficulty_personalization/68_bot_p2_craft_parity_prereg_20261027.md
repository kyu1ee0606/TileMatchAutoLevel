## 4. 판정 (P2 vs B′, "≤"는 1e-12 허용) — 62·65와 같다
1. 공동 MSE < B′
2. 클리어 MAE ≤ B′
3. 각 층(craft-random, craft-fixed)의 공동 MSE ≤ 1.10 × B′ 이거나, 증가분 ≤ 0.002
4. 실패 원인 오차(무조건부 Grass·Bomb·Normal 실패율의 MAE) ≤ B′

1~4를 모두 만족하면 지지다. TV는 보고만 한다. 목표 클리어 MAE ≤ 10%p와 AF 구간별 결과는 따로 보고한다.

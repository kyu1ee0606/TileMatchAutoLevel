## 4. 판정 (COMBO vs B, N 전체, "≤"에는 허용오차 1e-12)
1. 공동 MSE < B
2. 클리어 MAE ≤ B
3. 기믹 층별 공동 MSE ≤ 1.10 × B (모든 층)
4. **실패 원인 오차**: 무조건부 Grass·Bomb·Normal 실패율 MAE(세 범주 평균 |예측 − AF|) ≤ B

지지 = 1~4 모두 충족.

**TV(실패 시 조건부 분포)를 판정에서 빼는 이유** (결과 보기 전에 결정):
- 58에서 C는 폭탄 실패를 줄였고, 그만큼 남은 실패가 독 가득으로 옮겨갔다. TV는 실패한 판만으로 분포를 정규화한다. 그래서 클리어율이 95% 이상인 쉬운 맵에서는 수 %의 실패 질량만으로 TV 0~1이 결정되어 잡음이 크다. 같은 이동이 클리어 MAE·공동 MSE에도 반영되므로 이중으로 계산된다.
- 무조건부 범주 MAE는 같은 오차("어떤 이유로 몇 %가 실패하는가")를 실제 발생 빈도로 가중해 측정한다.
- TV는 전체·층별·AF 구간별로 **보고**한다. 판정에는 넣지 않는다.

**별도 보고**:
- 층별·AF 구간별 클리어 MAE, 실패 분포(AF / B / COMBO)
- tier 1만의 값
- 목표 클리어 MAE < 10%p
- Rp 재현성

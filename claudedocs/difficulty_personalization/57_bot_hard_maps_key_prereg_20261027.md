`key_container_dig`는 공개 정보만 쓰고, 잠긴 칸이 있을 때만 동작한다.
- 숨은 열쇠 수 = 3×잠긴 칸 − 독의 열쇠 − 보드에 보이는 열쇠.
  - 잠금 수는 공개 정보다. 게임은 열쇠 수 // 3칸을 잠근다.
- "열쇠 컨테이너" = 독에 대기 중인 열쇠가 나온 스택 또는 craft. 플레이어가 그 열쇠가 나오는 걸 봤다.
- 가점 조건(모두 충족):
  - 숨은 열쇠가 1장 이상
  - 이 픽이 열쇠 컨테이너의 현재 맨 위 또는 방출 타일
  - 열쇠가 아닌 타일(열쇠는 K1이 담당)
  - 빈 칸 ≥ 4. 픽 후에도 빈 칸 ≥ 3이어서 기존 위험 정의(빈 칸 ≤ 2, 55 §8) 밖에 머문다.
- 가점 크기 = `key_first_w`·s(θ). 기존 적합값을 재사용하며 새 적합 상수가 없다.
- 테스트(`tests/test_bot_key_dig_candidate.py`, 4건):
  - 옵션 OFF = 코어와 같은 선택 순서
  - 잠금이 없는 맵에서는 ON = OFF
  - ON일 때 열쇠 컨테이너 파기 가점 = w·s
  - 빈 칸 < 4이면 가점 없음
- 선택 sha `cd6860b8f1436192…`.

## 5. 판정 (후보 vs B, 후보별 독립. 판정식은 manifest에 기록)
**H** (P2, P12 각각):
- 공동 MSE < B
- 클리어 MAE ≤ B
- 실패 분포 TV 평균 ≤ B
- 층별(craft, key/stack) 공동 MSE ≤ 1.10×B

**K** (K1, K2 각각):
- **gate**: KD 공동 MSE < B. 실패한 후보는 KR·KN에서 제외한다.
- **KR**: 공동 MSE < B, 클리어 MAE ≤ B.
- **KN**: 공동 MSE < B, 클리어 MAE ≤ B, TV ≤ B, 열쇠 컨테이너 층별 공동 MSE ≤ 1.10×B.
- 지지 = 모든 조건 충족.

**별도 보고**(판정과 분리):
- 클리어 MAE ≤ 10%p 목표
- 맵별 AF / B / 후보의 clear·실패 분포
- key 맵 잠금 해제 판 비율(`unlocked_games`)

**규모**: 최대 H 4,800 + KD 2,880 + KR 5,760 + KN 7,680 = 21,120판. 누적 약 39,580 → 최대 약 60,700 / 100,000.

**한계(사전 기록)**:
- H는 10맵·2층뿐이다. 폭탄·풀·plain 층의 어려운 미사용 맵이 없어서다.
- KD·KR은 이미 사용한 맵이다.
- K 층(craft 6개)은 표본 잡음에 취약하다.
- K2는 KD 결과 열람 전에 정의했다(이 문서 sha로 고정).

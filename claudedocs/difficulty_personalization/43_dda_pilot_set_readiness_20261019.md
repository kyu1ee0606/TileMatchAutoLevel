## 6. 출시 순서와 하트 정책 (정본: 이 문서 + 문서 10 §9-13 · 29 §10 · 39 §G)

1. **출시 순서**: 신규 이벤트 안정화 → 실패 시 하트 소모 정책 테스트·안정화 → 동적 난이도 실제 실험. DDA 준비(분류·패키징·확인 측정 계획)는 계속하지만, **실제 적용은 하트 정책 안정화 이후이고 별도 승인이 필요하다.**
2. **데이터 시기 구분**: 지금 있는 AF(2026-09-08~10-19)는 모두 **변경 전 하트 정책 시기**다(현행은 진입 시 차감으로 추정, 문서 01 §6 [추정]). 변경 후 자료는 섞지 않고 별도 기간 태그로 집계한다. 실패 비용이 바뀌면 첫 시도 신중도, 도움(부스터·부활) 사용, 포기·이탈이 달라질 수 있다.
3. **변경 후 재검증 대상**:
   | 대상 | 이유 | 다시 볼 것 |
   |---|---|---|
   | 레벨별 기준선 p0(clean_ft, ft_any), help_rate, 무도움 하·상한 | 실패 비용 → 도움 사용·첫시도 행동 변화 | 변경 전후 같은 맵 차이(Wilson·버전별 z, 문서 22 드리프트 2.0~2.6%p와 비교) |
   | 클리어율 보정 모델 `cr-ftany-v24r-20261016`(10-14 AF 학습) | 학습 목표값 정의가 같아도 분포가 달라질 수 있다 | 변경 후 기간으로 시간 외삽 점검(문서 42 §4-3 방식) → 필요하면 재학습(별도 승인) |
   | 봇Δ→유저Δ 환산 β=0.429(변경 전 L1~31 자연실험) | 실패 비용이 유저 반응 크기를 바꿀 수 있다 | 파일럿 기울기는 **변경 후 기간 자료로만** 추정한다. 변경 전 β는 사전 등록 비교값으로만 쓴다 |
   | 파일럿 21 선정(p0 구간·천장 여부), 검정력(일일 n), 가드레일(24h 복귀·다음 레벨 진입) | p0·트래픽·이탈 기준선 이동 | 변경 후 2주 전후 기준선으로 구간·SE를 다시 계산하고, A/A 점검을 다시 한다 |

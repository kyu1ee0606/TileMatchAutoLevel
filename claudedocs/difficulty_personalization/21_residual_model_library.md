## 0. 결론
1. **직접 구현은 맞다.** sklearn Ridge와 비교하면 20개 폴드 모두에서 λ 선택이 같고, 예측 차이는 최대 1.9e-14(부동소수 오차)다. logit 매핑도 sklearn LinearRegression과 4e-16 차이다. sklearn GradientBoosting(같은 설정)의 K-fold 지표도 직접 GBM과 같다(MAE 0.068, tolAF 0.677). 20의 정확도 수치는 그대로 유효하다.
2. **정확도는 라이브러리로 바꿔도 거의 늘지 않는다.** 410레벨 K-fold에서 모든 모델이 MAE 0.067~0.072 안에 있다. 반복 간 표준편차가 ≤0.002라서 0.001~0.002 차이는 의미가 없다. 직접 구현 c+(0.067 / tolAF 0.693 / ρ 0.744)가 여전히 최상위권이다. E1 = Ridge+LightGBM 단조(0.068 / 0.686 / 0.739)는 사실상 같다. 이 표본에서는 **봇 입력과 특징이 정확도를 정하고, 알고리즘은 정하지 않는다.**
3. **라이브러리로 얻는 실제 이득**:
   - **외삽**: 트리 계열(RF·HistGB·LightGBM)은 L32~300 → 301~500에서 MAE 0.082~0.085를 낸다. 선형 모델은 0.098~0.100이다. LightGBM 단조는 편향이 −0.007로 가장 작다. 앵커 10레벨로 편향만 보정하면 모델 차이는 다시 줄어든다(0.087~0.094).
   - **예측 구간**: LightGBM 분위수(10%·90%)만 쓰면 포함률이 0.73으로 목표 미달이다(소표본 분위수는 구간이 좁게 나온다). 여기에 **CQR 보정**(안쪽 CV 잔차로 폭을 넓힘)을 더하면 **0.83**(구간: 익숙한 기믹 0.83, 새 기믹 0.85, 세 레벨 구간 0.82~0.85)이다. 20의 대칭 ±w conformal은 0.81이다. 대신 폭이 0.26으로 20의 0.22보다 넓다. 장점은 구간이 레벨마다 비대칭·가변 폭이라는 점이다.
   - **해석**: SHAP으로 레벨마다 "봇 성공률 +5%p, grass −3%p" 형태의 근거 3개를 바로 낼 수 있다(§5). 직접 구현으로는 순열 중요도(전역)만 가능했다.
   - **유지보수**: 데이터 교체 후 재학습이 표준 API 한 줄이다. 단조 제약·조기종료·분위수 손실을 직접 구현할 필요가 없다.
4. **채택 권장 = E1 (sklearn Ridge + LightGBM 단조, logit 평균) + LightGBM 분위수 CQR 80% 구간 + SHAP 근거.** 이유는 세 가지다. c+와 정확도가 같고(차이 0.001, 잡음 수준), 단조 제약으로 "봇이 더 잘 깨면 예측도 오른다"가 보장된다. 그리고 SHAP이 정확히 분해된다(선형 SHAP + TreeSHAP의 평균 = 예측 logit). 직접 GBM은 SHAP 지원이 없다.
5. **20 문서 정정 1건**: 20 §6의 "노출 적은 기믹 MAE 0.148 vs 익숙 0.074"는 **집계 버그**다. `r["novelty"] > 0.5 or r["gimmick_first"]`가 int 배열을 만들고, 그 배열로 인덱싱하면 0번·1번 레벨만 반복 선택된다. 올바르게 계산하면 c+ OOF 기준 **새 기믹 0.066 = 익숙 0.066**이다. novelty가 특징으로 들어가 있어서 K-fold 안에서는 차이가 사라진다. 처음 보는 기믹의 위험은 기믹 단위 홀드아웃(grass 0.16~0.17)으로 판단해야 한다. 이번 신뢰도 규칙은 그 결과를 근거로 다시 정했다(§5-3). `residual_model.py`는 지시 범위 밖이라 고치지 않았다.
6. **처음 보는 기믹 문제는 어느 모델로도 풀리지 않는다.** grass를 통째로 빼고 학습하면 10개 모델 모두 MAE 0.160~0.173, 편향 +0.15~0.16이다. 20의 결론(봇이 재현하지 못하는 기믹은 AF 데이터가 생기기 전에는 예측할 수 없다)이 라이브러리 모델에서도 같다.

## 3. 모델 비교 (같은 검증 체계)
설정은 모두 "단순·규제 우선"이다. 410레벨 × 48특징이기 때문이다.
- L1 Ridge: λ는 안쪽 CV로 고른다(20과 같음).
- L2 로지스틱(분수 목표): 각 레벨을 y=1(가중 mid) + y=0(가중 1−mid)로 넣는다. C는 안쪽 CV로 고른다.
- L3 RF: 300그루, 잎 ≥5, max_features 0.33.
- L4 HistGB: 깊이 3, 잎 ≥10, L2 1.0, 단조 제약, 조기종료(검증 20%, 30회).
- L5 LightGBM: 깊이 3, 잎 7개, 잎 ≥10, L2 1.0, 행·열 부표본 0.8·0.7, 학습률 0.03. 조기종료는 학습 폴드 안의 20% 검증으로 하고, 라운드 수를 정한 뒤 전체 재학습한다(중앙값 194라운드). **단조 제약**: lg055·lg065·lg085·lg100 → +1. L5u는 같은 설정에서 제약만 뺀 것이다.
- E1 = ½(L1 + L5) logit 평균, E2 = ¼(L1 + L2 + L4 + L5).

## 4. 예상 범위 (80% 구간)와 등급
K-fold 1회차(맵 해시 그룹 5겹) OOF 기준이다. 분위수 모델은 L5와 같은 설정이고 목적함수만 quantile(α 0.1 / 0.9)이다. **LightGBM은 quantile 목적함수에 monotone_constraints를 허용하지 않아서**(`Cannot use monotone_constraints in quantile objective`) 분위수 모델만 무제약이다. CQR은 바깥 학습 폴드 안에서 5겹 점수 E = max(q10 − y, y − q90)를 구하고, 그 80% 분위(유한표본 보정)만큼 양쪽을 넓힌다. 보정폭은 폴드별 logit +0.15~+0.22다.

| 방식 | 부분 | n | mid 포함 | [LB, UB] 겹침 | 평균 폭 | 중앙 폭 |
|---|---|---|---|---|---|---|
| LGBM 분위수 (원본) | 전체 | 410 | 0.727 | 0.856 | 0.210 | 0.193 |
| **LGBM 분위수 + CQR** | 전체 | 410 | **0.832** | **0.915** | 0.263 | 0.250 |
| | 익숙 / 새 기믹 | 308 / 102 | 0.825 / 0.853 | 0.909 / 0.931 | 0.256 / 0.284 | |
| | 32-100 / 101-300 / 301-500 | 60 / 180 / 170 | 0.850 / 0.833 / 0.824 | 0.983 / 0.911 / 0.894 | 0.234 / 0.260 / 0.277 | |
| (20) 직접 conformal ±w | 전체 | 410 | 0.805 | 0.905 | 0.220 | — |

- 분위수 회귀만 쓰면 **목표 80%에 못 미친다(0.73)**. 410레벨에서 10%·90% 꼬리를 학습하면 구간이 좁게 나온다. 운영하려면 CQR 보정이 필수다.
- CQR은 목표를 조금 넘는다(0.83, 약간 보수적). 20의 대칭 구간(0.81 / 폭 0.22)보다 폭이 넓다. 폭 효율만 보면 20 방식이 낫다. CQR의 이점은 구간 모양이 레벨마다 다르다는 점이다(예: 기믹 없는 레벨 L146 [0.77, 0.96]처럼 상한 쪽이 좁다). 그리고 새 기믹·301+ 구간에서 폭이 자동으로 넓어진다(0.284 / 0.277).
- 등급(컷 S ≥0.90 · A ≥0.80 · B ≥0.65 · C ≥0.50): E1 점예측 **정확히 일치 0.55, ±1등급 0.96**. AF 등급이 구간에서 나온 등급 범위 안에 드는 비율은 0.97이다. 20 c+(0.54 / 0.96)와 같다.

## 5. 해석 (SHAP)
E1 = ½·Ridge + ½·LightGBM (logit). Ridge는 선형 SHAP(w·표준화 x, 학습 평균 기준)으로, LightGBM은 TreeSHAP으로 분해하고 둘을 평균했다. 각 레벨의 기여 합 + 기준값이 그 레벨의 예측 logit과 정확히 같다. 레벨별 근거는 **그 레벨을 학습하지 않은 폴드 모델**로 구했다(OOF). %p는 "그 묶음을 빼면 예측이 얼마나 변하나"로 환산했다: p − expit(logit − 기여).

### 5-3. 신뢰도 규칙과 검증
규칙: **low** = 첫 등장이거나, novelty > 0.5이거나, 학습셋에서 10레벨 미만인 기믹을 포함. **medium** = grass·chain 포함(봇이 실패 경로를 재현하지 못하는 기믹, 20 §7). **high** = 나머지.

| 신뢰도 | n | MAE (E1 OOF) | CQR 80% 포함 |
|---|---|---|---|
| high | 235 | **0.062** | 0.82 |
| medium | 73 | 0.081 | 0.84 |
| low | 102 | 0.069 | 0.85 |

- high < medium 순서는 맞다. low(노출 적음)는 K-fold 안에서는 medium보다 오히려 낫다. 결론 5와 같은 이유다(novelty가 특징이고 같은 기믹 레벨이 학습에 있음). K-fold는 "진짜 처음 보는 기믹"을 재현하지 못한다. 그 경우의 근거는 기믹 단위 홀드아웃(grass 0.16, 나머지 0.05~0.09)이다. → low는 "기믹이 진짜 새로우면 grass급 오차 가능"을 경고하는 등급으로 유지한다. 실제 정확도 신호로 쓸 수 있는 것은 high vs medium 차이(0.062 vs 0.081)다.

## 7. 한계
- 표본 410레벨. 모델 간 차이(≤0.003)는 반복 간 잡음(sd ≤0.002)과 같은 크기라서 순위를 정할 수 없다.
- 하이퍼파라미터는 "얕게·규제" 고정값과 조기종료만 썼고 격자 탐색은 하지 않았다(소표본 과적합 회피). 탐색을 해도 MAE 바닥(≈0.03, 20 §6)과의 격차는 봇 쪽 원인이 대부분이다.
- 분위수 LightGBM에는 단조 제약을 걸 수 없다(라이브러리 제약). 그래서 구간 경계는 봇 성공률에 대해 단조가 보장되지 않는다(점예측은 보장됨).
- 구간·SHAP 예시는 K-fold 1회차만 썼다. 외삽은 한 번 자른 결과다.
- 신뢰도 규칙의 low 등급은 K-fold로는 검증되지 않는다(§5-3). 진짜 신규 기믹이 나왔을 때 AF로 확인해야 한다.

# CHANGELOG 2026-07-06 — 보스 템플릿 반자동 제작 시스템

## 요약
프로덕션 보스(10의 배수) 레벨을 **모양=수동 그림 / 타입·기믹·검증=자동**으로 만드는 전용
워크플로우. 디바이스 가독성(≤8)으로 10x10 템플릿 크롭이 한계라 직접 찍는 방식 도입.

## 배경
- GameBoost 10x10 보스 템플릿 → 인게임 타일 과소 → 사용불가. 크롭은 B타입만 가능(D타입 불가).
- 보스는 스토리(할아버지 정원 챕터) 연계 + 주변 일반레벨보다 어려운 마일스톤 필요.

## 구성

### 1. 에디터 (🏰 보스 템플릿 탭, `BossTemplatePanel.tsx`)
- **다층 t0 그리기**: 층 선택 + 드래그 페인트. 짝수층 8·홀수층 7 자동(게임 홀짝).
- **인게임 충실 미리보기**: worldX/Y 좌표공식 + 홀짝 0.5 오프셋 + 층 스택(상위=앞).
- **수동 기믹 팔레트**(세로): ice/chain/grass/frog/bomb/curtain. 셀별 지정. 자동배치가 보존.
- **단일 보스 레벨 배정**(구간 아님): level_min==max. 저장/로드/삭제.
- **스토리 컨셉 노트**: 보스레벨별 챕터/비트/deco/모양 편집 테이블, 1~5챕터(할아버지 정원)
  10~100 사전입력. "그리기" → 보스레벨 세팅 연동.
- **난이도 파악** (RL 예측 클리어율): 현재 편집중 템플릿 + 3레버
  - 목표난이도 = 보스레벨 → 톱니바퀴 곡선 자동
  - 기준 실력(skill_mean) 슬라이더 (기본=프로덕션 슬라이더값)
  - 타일 종류 슬라이더 (기본=hard_steep 그래프값)
  → 예측/목표 클리어율 + 타일종류·타일수 표시(작음/부족 경고).

### 2. 백엔드 (`analyze.py`)
- 스토어: `boss_templates.json`, `boss_concepts.json` + CRUD 엔드포인트.
- `POST /generate/from-boss-template`: 저장분(또는 인라인 layers=미리보기) → 다층 t0 조립
  + useTileCount + 기믹 자동 + ÷3/OOB/link/inner 정화.
  - **인라인 layers**: 저장 없이 현재 편집분 미리보기.
  - **use_tile_count_override**: 슬라이더 종류수 직접 적용.

### 3. 난이도 오버레이 (자동)
- **타일 종류**: 그래프값 + 보너스1, 레벨대별 floor. override 시 직접값.
- **기믹**: 언락/난이도 기반 속성기믹(`_add_obstacles`) + craft/stack 골 자동배치.
  - 저레벨(11~30) 언락 기믹이 craft/stack뿐 → 컨테이너 골로 기믹 확보. 상위층 t0 셀 변환,
    craft 출력방향 빈칸 확보, goalCount 누적.
  - `_add_obstacles`가 속성있는 타일 건너뛰므로 **수동 기믹 자동 보존**.

### 4. 순차검증 정합 (`ProductionDashboard`)
- `handleRegenerateLevel`: `level_json._boss_template_id` 있으면 from-boss-template로 재생성 →
  모양/useTileCount/기믹 유지. (프로시저 경로로 빠져 어긋나던 문제 차단.)
- 보스 생성/재생성에 `tile_type_profile` 전달 → 배치 그래프 정합.
- Test탭 **🏰 보스레벨만 재생성** 버튼.

## 레벨대별 난이도 완화 (초반 튜토리얼 보호)
초반 보스(10~30)는 언락 기믹 부족+테마1(입문)이라 과도한 난이도 위험 → 완화:

| 구간 | 타일종류 floor | 목표 클리어율 스케일 |
|---|---|---|
| 10~30 | 없음(그래프값 ~6~7) | ×0.75 (마일드 스파이크) |
| 40~100 | 8 | ×0.65 |
| 110+ | 9 | ×0.5 (본격 보스) |

## 스토리 연계 (참고)
게임 실데이터 decoration_list 기반: 1~5챕터(테마1 "잊혀진 온기", 할아버지 정원).
챕터당 최종 deco = 보스 피날레 상징물(우체통/꽃차/젤리조명/빨간우체통/할아버지편지액자).
star 소모: 실데이터 챕터당 20(설계문서 14는 stale). 테마2(6~10)=37/챕터.
⚠️ 챕터별 실 star cost = GameBoost 서버 런타임 로드, repo에 없음(설계 목표값만 확인).

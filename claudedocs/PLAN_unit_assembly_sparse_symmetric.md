# 유닛 조립 재설계 계획 — 성긴 대칭 + 봇클리어

작성: 2026-07 세션. 상태: **계획(착수 전)**. 현재 unit_assembly는 생산 OFF(회귀로 강제 비활성).

## 1. 배경 / 문제 진단

### 증상
- unit_assembly 켜고 프로덕션 생성 → RL 순차검증 통과 1300/1500 → 급락.

### 근본 원인 (변수 격리로 확정)
| 조합 | RL 봇 클리어율 |
|------|---------------|
| unit_assembly=F, reverse=F (정상) | 0.67~0.79 ✅ |
| unit_assembly=F, reverse=T | 0.03~0.21 ❌ |
| unit_assembly=T, reverse=F | 0.0~0.69 (편차·데드락) |
| unit_assembly=T, reverse=T | 0.0~0.33 ❌ |

1. **reverse_generation = 봇-하드 주범**: witness-peeling으로 solvable하나 **좁은 1개 경로** → RL 봇(휴리스틱)이 못 찾음. max_open 튜닝 무효.
2. **조밀 unit_assembly = ~40% 데드락**: reverse 제거해도 조밀 구조가 언클리어러블 유발.
3. 선택가능 타일률은 ON/OFF 비슷(~24%) → 단순 커버리지 문제 아님, 구조+타입배정 문제.

### 이미 처리한 것 (생산복구 커밋)
- unit_assembly 강제 OFF (localStorage v2).
- Lv11-30 +1층 원복, tile_range(60→30-48) 원복, min60은 `_unit_assembly`에만.
- **reverse↔unit_assembly 커플링 제거** (genModeFields/RLSimulationPanel/analyze.py).
- generator: unit_assembly면 **deadlock 체크 강제**.
→ reverse 제거로 0.0→0.5~0.8 개선됐으나 **조밀 데드락 잔존** → 아래 재설계 필요.

## 2. 목표 설계 — 성긴 대칭 유닛 + 기본템플릿 추가층

### 핵심 개념
```
레벨 = [기본 템플릿 층들]  +  [난이도용 유닛 대칭층 N개]
        └ 디자인된 모양(패턴/템플릿)   └ 성긴 대칭 유닛(봇 클리어 가능)
```
- **기본층** = 패턴/템플릿의 디자인 모양(look 유지).
- **추가 유닛층** = 난이도 올릴 때 유닛 대칭 조합으로 얹음(템플릿에 없는 새 층).
- 추가층 = **성김**(sparse) → 봇 클리어 가능 + 비주얼 코히어런트(랜덤 흩어짐 아님).

### 규칙 (확정)
| 요소 | 결정 |
|------|------|
| 기본 템플릿 층 | 패턴/템플릿 고정 모양 |
| 추가 유닛층 수 N | 난이도로 결정 |
| 유닛 크기 | 난이도(쉬움=3·6칸, 중간=9·12, 어려움=12·15) |
| 유닛 개수/층 | **1~3 고정** (조밀폭주 방지) |
| 배치 | 좌우/상하 **대칭** (유닛+미러) |
| min60 타일 | **폐기** (성김·봇클리어 우선, 타일수는 결과값) |
| 역전(밀도베이스) | **제거** (조밀 주범) |

### 난이도 → 크기/개수 매핑 (초안, 봇검증으로 튜닝)
| target_difficulty | 유닛 크기 | 유닛 수/층 |
|---|---|---|
| <0.3 | 3 | 1~2 |
| 0.3~0.5 | 6 | 2 |
| 0.5~0.7 | 9~12 | 2~3 |
| >0.7 | 12~15 | 3 |

## 3. 필수 불변식 (검증 게이트)
- **RL 봇 클리어율 정상**(0.0 아님, 목표 근처) — 최우선. 크기 매핑 튜닝 기준.
- reverse_generation **강제 안 함** (봇하드).
- deadlock 체크 **ON** (언클리어러블 필터).
- floating 0 (유닛층이 아래층 받침 = valid_support_mask 준수).
- ÷3 (매칭 타입) — 정상 타입 파이프라인.
- 대칭 (좌우/상하).

## 4. 구현 단계
1. **[선결 완료]** reverse 제거 + deadlock 강제 — 이번 커밋.
2. **성긴-대칭 유닛층 빌더** (`_build_unit_assembly_layers` 재작성):
   - 바닥 = 주 패턴(유지).
   - 위층 = 크기별 1~3 유닛 대칭 배치(성김). budget-fill(조밀) 제거.
   - 역전/floating-repair 로직 제거·단순화.
3. **"기본템플릿 + 유닛 추가층 N"** 통합 (층수 N을 난이도로).
4. **각 단계 RL 봇 클리어율 검증** (Lv30/100/400/800, 0.0 아닌지).
5. 통과 확인 후 unit_assembly 재활성 (localStorage 안내).

## 5. 확장 아이디어 (추후)
- 템플릿에 없는 층을 유닛조합으로 무한 생성 → 새 템플릿 안 그려도 난이도 층 추가.
- 패턴 디버그 탭 "레벨 고정 패턴" 폴더(별도 계획 `PLAN_level_pattern_pin.md` 예정)와 조합.

## 6. 리스크 / 확인
- 성김 → 타일수↓ → 초반 레벨 목표난이도와 매칭되는지(배치 best-of-N이 흡수).
- 고레벨(400+) 데드락은 기존 문제(내 세션 무관) — 별개 튜닝.
- 재활성 전 반드시 **배치 생성 → 순차검증 통과율** 실측(단일샷 아님).

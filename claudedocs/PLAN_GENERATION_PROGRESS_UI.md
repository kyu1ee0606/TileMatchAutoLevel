# PLAN — 생성 진행 UI 개선 (현재 생성중 레벨 / 목표 표시)

**상태**: 계획만 수립. 현재 생성 작업 완료 후 적용 예정.
**작성**: 2026-07-03

## 배경
현재 GenerateTab 진행 패널은 `완료 720/1500 · %`만 표시. **지금 몇번 레벨을 만드는 중인지**
(current_level)와 자동큐의 배치 진행이 안 보임/분리됨.

## 조사 결과 (데이터 가용성)
- `progress.current_level`: **이미 존재**하고 생성 중 세팅됨(`index.tsx` ~1467줄 `current_level: lastLevelNum`).
  단 UI에 미표시.
- `autoQueueMade`/`autoQueueTarget`: 자동큐 패널에만 표시, 진행바와 분리.
- 즉 **신규 상태 불필요, UI 렌더만 추가**.

## 개선안

### P1 — 현재 생성중 레벨번호 (핵심, ~5줄, 리스크 0)
- 진행바 상단 문구: `완료 720 / 1500 · 🔨 Lv.721 생성 중 · 48.0%`
- `progress.current_level` 활용.
- 위치: `GenerateTab` 진행 패널 메인 진행바 헤더(약 2834줄 `완료: {completed}/{total}` 라인).

### P2 — 자동큐 배치 진행 통합 (~10줄)
- 통합 헤더(autoQueueRunning 시): `📦 배치 2/3 · 🔨 Lv.721 · 레벨 720/1500 (48%)`
- 옵션: 전체 진행 `전체 2220/4500`(target×1500 분모, target=0이면 생략).
- 위치: 자동큐 패널 진행표시 + 메인 진행바 연계.

### P3 — 완료 배치 요약 미니 (선택, ~15줄)
- `✅배치1(1500) ✅배치2 🔨배치3` 리스트 — 야간 운용 후 결과 일람.

## 적용 순서
P1(즉효) → P2(자동큐) → P3(여유)

## 건드릴 파일/지점
- `frontend/src/components/ProductionDashboard/index.tsx`
  - 진행 패널 JSX ~2832~2868 (P1 문구)
  - 자동큐 진행표시(패널+진행바) (P2)
- 신규 상태/타입 불필요.

## 검증
- `npx tsc --noEmit`
- 생성 중 실제 진행표시 확인(Playwright or 수동).

## 0. 결론
1. **v2.1 기준선이 21 문서와 정확히 같게 재현됐다**: E1 MAE 0.068 / tolAF 0.686 / ρ 0.739.
2. **v2.3 입력의 E1은 v2.1과 동률이다**: MAE 0.067(반복 sd 0.0014) / tolAF 0.684 / ρ 0.743. 모든 차이가 0.002 이내이거나 반복 잡음 수준이다.
   - 봇 원점수 순위(θ0.85 ρ 0.567 → 0.602, 19)는 좋아졌다. 하지만 보정 모델은 v2.1에서도 그 차이를 레벨 특징(has_chain·has_craft·has_teleporter 등)으로 이미 흡수하고 있었다. 20 문서의 "보정항이 흡수" 판단과 같다.
3. **검증 게이트(사용자 승인 기준) — 전체**:

4. **불합격 원인 추정**:
   - **ρ 0.78**: AF 자체의 재현 ρ가 0.79~0.90이다(22 문서). 410레벨 중 AF 범위가 좁고 클리어율이 높은 레벨이 많아 순위 변별이 작다. 구간별로는 32~100 0.60, 301~500 0.66으로 특히 낮다. 봇 입력을 바꿔도 E1 ρ가 0.739 → 0.743만 움직였다. 이 게이트는 지금 특징 구성으로는 **봇 개선만으로 넘기 어렵다**.
   - **tolAF 0.69**: v2.1(0.686)과 v2.3(0.684) 모두 경계 바로 아래다. 차이(0.002)는 반복 잡음이다.
   - **chain·grass**: 봇 원점수에서는 체인이 확실히 좋아졌다(체인 상대 MAE 0.163 → 0.144, 19 §6). 그런데 보정 모델 특징에는 봇 실패 형태 중 **폭탄·풀 비중만 있고 체인 비중이 없다**. 그래서 v2.3의 체인 실패 재현이 모델에 전달되지 않는다. 풀은 봇이 여전히 실패 경로를 절반만 재현한다(46% 대 79%).
   - → 다음 재학습에서 **봇 체인 실패 비중 특징 추가**를 제안한다(이번에는 지시대로 특징·모델을 바꾸지 않았다).
5. **novelty 집계 버그 수정**(`residual_model.py` §6, 21 §0-5): `x > 0.5 or gimmick_first`가 int 배열을 만들어 0·1번 레벨만 골랐고 `~nov`도 비트 반전이 됐다. bool 마스크로 고쳤다. v2.3 입력 c+ 기준 **새 기믹 0.070 (102레벨) / 익숙 0.066**이다(버그 값: 0.148 / 0.074).

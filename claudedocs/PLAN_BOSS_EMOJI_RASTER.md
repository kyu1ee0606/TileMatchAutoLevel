# PLAN — 보스 템플릿 이모지/글리프 래스터화 (모양 자동생성)

**상태**: 계획만. 미착수.
**목표**: 보스 템플릿 탭에서 이모지 선택/입력 → 8×8(홀짝 7) 그리드로 자동 래스터 →
현재 다층 편집기에 반영 → 인게임 프리뷰로 즉시 확인.
**근거 조사**: 자동화 가능성 검토(대화). 이모지 래스터=결정적·무료·즉시·범용.

---

## 1. 동작 개요

```
이모지 입력(🐱/⭐/💌) 또는 팔레트 선택
  → offscreen canvas에 렌더(폰트)
  → 8×8(또는 7×7) 다운샘플 + 임계값(alpha/luminance)
  → 켜진 픽셀 = t0 셀 → 현재 활성 층 positions 로 주입
  → 인게임 충실 프리뷰(기존)로 확인
```

핵심: **순수 프론트**(canvas 2D). 백엔드 변경 없음. 기존 편집기/프리뷰/저장 그대로 재사용.

---

## 2. UI 추가 (BossTemplatePanel)

- **이모지 팔레트 섹션** (그리드 편집기 근처):
  - 자주 쓰는 이모지 버튼들(스토리 연계: 🐱 💌 📮 🪑 ☕ 🏰 🐾 📖 🌹 🌷 🖼️ ⭐ ❤️ 🌸 🌿 …)
  - **직접 입력** 텍스트필드(임의 이모지/문자 1자)
  - **해상도 표시**: 현재 활성 층 크기(8 or 7)에 맞춰 래스터
- **적용 옵션**:
  - `현재 층에 적용` / `전 층에 적용`(타워) / `층별 축소 적용`(피라미드=erosion)
  - `대칭 보정`(both) 토글 — 이모지 비대칭 보정
  - `임계값` 슬라이더(픽셀 on/off 민감도) — 너무 성기거나 뭉치면 조절
- **미리보기**: 래스터 결과를 편집 그리드에 즉시 반영(되돌리기 위해 적용 전 프리뷰 오버레이 권장)

## 3. 래스터 알고리즘 (프론트)

```
rasterizeEmoji(char, size /*8 or 7*/, threshold):
  canvas = offscreen(size*S, size*S)  // S=렌더배율(예 16) → 안티에일리어싱 여유
  ctx.font = `${size*S*0.8}px system emoji font`
  ctx.textAlign/Baseline = center
  ctx.fillText(char, center, center)
  # 셀별 샘플: 각 셀 영역 픽셀 alpha 평균 > threshold → on
  for cy in 0..size-1:
    for cx in 0..size-1:
      a = 셀영역 평균 alpha
      if a > threshold: positions.add(`${cx}_${cy}`)
  return positions
```

- **홀짝 크기 대응**: 활성 층이 8이면 8×8, 7이면 7×7로 각각 래스터(중앙 정렬).
- **좌표 규칙**: 게임과 동일 "col_row", row0=위 → canvas y=0=위 그대로 매핑(일치).
- **결정적**: 동일 이모지+임계값 → 동일 결과.

---

## 4. 다층 처리 (선택 옵션)

| 옵션 | 방법 |
|---|---|
| 타워 | 전 층에 동일 이모지 래스터(각 층 홀짝 크기로) |
| 피라미드 | 상단=원본, 하단으로 morphological **erosion**(테두리 1겹씩 깎기) → 좁아짐 |
| 층별 다른 이모지 | 층 선택 후 각각 이모지 적용(수동) |

기본 = 현재 활성 층만. 전층/피라미드는 버튼.

---

## 5. 검증/보정 (자동생성 공통)

- **÷3**: 총 셀수 표시 + ÷3 근접 경고(기존). 생성 finalize가 최종 보정.
- **최소 타일수**: 너무 적으면(작은 이모지) "쉬움" 경고(기존 난이도 파악 연계).
- **대칭 보정**: on이면 좌우 미러 합집합(모양 안정 + 클리어 유리).
- **클리어가능**: 저장/생성 후 기존 RL/솔버 파이프로 확인(별도).

## 6. 구현 범위 (프론트 only)

- `BossTemplatePanel.tsx`:
  - 이모지 팔레트 + 입력 + 옵션 UI 섹션 추가
  - `rasterizeEmoji()` 유틸(canvas)
  - 적용 핸들러(현재층/전층/피라미드) → layers positions 갱신
  - erosion 유틸(피라미드용)
- 백엔드/스토어/생성 파이프 **무변경**(래스터 결과 = 기존 t0 positions와 동일 형식).

## 7. 단계 (착수 시)

1. rasterizeEmoji 유틸 + "현재 층 적용" (MVP) — 이모지→8×8 셀
2. 팔레트 + 직접입력 + 임계값 슬라이더
3. 전층/피라미드/대칭 옵션
4. (후속) 컨셉 노트 shape 이모지 → 일괄 자동생성 버튼(150개 초안)

## 8. 리스크/한계

- **저해상도 뭉갬**: 8×8은 복잡한 이모지 뭉개짐 → 단순 실루엣 위주. 임계값/대칭으로 완화.
- **폰트 의존**: 이모지 렌더가 OS/브라우저 폰트 따라 다름 → 결과 편차 가능(같은 기기 내 결정적).
- **글리프 정렬**: 이모지별 baseline/여백 차이 → 중앙정렬 + 여백 트림 필요.

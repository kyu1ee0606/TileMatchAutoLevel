**과대예측 위험(정정)**: 위 쏠림의 방향은 "실제로 어려운 맵을 쉽게(높게) 예측"이다. 선별에서 이것은 다음 순서로 나타난다.
1. 실제 성공률 60%인 후보를 모델이 80%로 예측한다.
2. 목표 80%에 가장 가까운 후보로 선택된다.
3. 배포된 맵은 **목표보다 어렵다**(실측 60%).

선택 압력은 이 방향을 키운다 — 후보 중 "예측이 목표에 맞는" 것을 고르면 과대예측된 후보가 더 자주 뽑힌다(승자의 저주, 31 §4-1 −1~−3%p, 저성공 목표에서 가장 큼). 반대 방향(목표보다 쉬운 맵이 뽑히는 것)은 고성공 천장 구간(≥0.96, 편향 −0.010, 26 §11-9)에서만 작게 나타난다. 이 문서와 앞 문서에서 "쉽게 예측"이라고 쓴 곳은 모두 **"예측 클리어율이 실제보다 높다 → 선택된 맵은 목표보다 어렵다"** 로 읽는다.

### 2-4. 계획에 주는 결과
- 신규 후보 15레벨은 학습 사례를 늘리지만 기울기 −0.57 쏠림을 직접 줄이지 않는다. 확장 후에도 저성공 구간 편향을 다시 재고(§6 E2 완료 조건), 줄지 않으면 모델 쪽 조치(예: 저성공 구간 가중·구간별 잔차 모델 — **탐색 항목**, §3-5 규칙 적용)를 별도 제안한다.
- L501+ 11레벨은 측정해도 `LEVEL_OUT_OF_RANGE`(32~500) 밖이다. 이 레벨들은 지원 범위 확장(501~1000 77레벨 측정, §6 E2)과 함께 다뤄야 의미가 있다. 501+ 도달 유저 θ 중앙값은 5.0~5.25로 301~500(4.48)과 다르다(31 §0).
- 측정 비용(35a §4): 35a는 6θ × 128 = 768판/레벨(11레벨 8,448판)로 계산했다. 현재 모델 프로토콜은 `theta4x128_v1`(4θ × 128 = 512판)이라 **5,632판**이면 된다(§8-3).

### 3-3. 신뢰 판단 — 85%는 경계선이 아니다
- 85%는 26 §11-9·34에서 "실제 <0.85 구간은 MAE 0.127·편향 +0.118"이라는 **검증 오차 요약**이다. 어려운 레벨의 정의도, 그 위에서 안전하다는 보장선도 아니다(0.85~0.92도 편향 +0.031, ±5%p 적중 0.67).
- 예측값 기준 경고("예측<85%면 저신뢰")만 두면 과대예측된 맵이 빠져나간다: **실제 80% 맵을 90%로 예측하면 경고가 없다.** 그런데 이것이 §2-3의 가장 흔한 실패 형태다.
- 그래서 신뢰는 **운영 시점에 알 수 있는 정보**로만 판단한다.

| 정보 | 내용 | 출처 |
|---|---|---|
| 학습 지원·배치 위치 | 배치 레벨이 학습 구간(32~500) 안인가, 냥이·시간 제한 레벨인가(G1·G4), 목표가 그 구간 학습 목표 p5~p95 안인가 | guard 기존 코드 + G1·G4 |
| 유사 맵 표본·검증 오차 | 같은 구간·같은 기믹 조합의 학습 레벨 수, 그 묶음의 OOF MAE·편향 | 학습 산출물 manifest에 묶음별 요약 추가(제안) |
| 예측 구간 폭·구간별 편향 | 80% 범위 폭(logit), **목표가 속한 구간**의 OOF 편향(예: 목표 <0.85면 +0.118) | 목표는 기획 입력이라 운영 시 알 수 있음 → 목표 기준 경고는 유효 |
| 새 기믹 조합·특징 범위 이탈 | `GIMMICK_UNSEEN/LOW_TRAIN`, `FEATURE_OOD`, `NOVELTY_HIGH`, 폭탄+신규 기믹 조합(35a §2-1 편중) | guard |
| 금지 | 신규 맵의 실제 성공률·도움 사용률·no_end | 출시 후 값 |

- 목표 기준 저신뢰(목표 <0.85)는 유지한다 — 목표는 알 수 있고, 그 구간의 검증 오차가 크다는 것이 사실이기 때문이다. 예측값 기준 경고는 보조로만 남기고 그것만으로 "신뢰 가능"이라 판단하지 않는다(G5).

### 3-4. 선별·판정 — 네 축 분리
| 축 | 질문 | 제안 기준(검증 근거) | 미충족 시 |
|---|---|---|---|
| ① 목표 차이 | 예측이 목표 폭 안인가 | 기본 폭 logit ±0.7(31 D5). `p_in_band ≥ 0.5`(31 §3-3). 근거: 379 재현에서 E1 최근접 적중 0.59~0.75 vs 무작위 0.35~0.47(31 §4-4) | **불합격**(재생성 대상) |
| ② 불확실성 크기 | 80% 범위가 판단에 쓸 만큼 좁은가 | 학습 OOF 범위 폭 분포의 상위 분위(예: p90) 이하. 수치는 구현 시 OOF에서 산출(참고: 31 §3-3 평균 폭 0.26) | **근거 부족** |
| ③ 학습 지원 범위 | §3-3 표의 hard 항목에 걸리지 않는가 | 억제 코드·G1·G4·`TARGET_OUT_OF_SUPPORT` 없음 | **근거 부족** |
| ④ 분리 시드 확인 | 확인 시드 C로 재측정·재예측했는가 | C 값으로 ①~③ 재통과, S→C 예측 이동 기록 | **근거 부족**(`SELECTION_UNCONFIRMED`) |

- 판정: ③·④·② 중 하나라도 미충족 → 근거 부족. 모두 충족하고 ① 충족 → 합격. ① 미충족 → 불합격. 순서는 31 §3-3과 같은 정신(근거 부족이면 억지로 합격시키지 않음).
- `in_range80`(목표값이 80% 범위 안에 드는지)은 **참고 표시**다. 합격 조건이 아니다 — 범위가 넓으면 아무 목표나 들어가므로 판단력이 없다.
- 선별 점수(후보 순위): `|logit p̂ − logit t| + λ·(80% 폭)`, λ 0.25 시작(31 §4-1: ±5%p 적중 0.37→0.44). 조정에 쓴 데이터는 이후 독립 검증에서 제외.
- 임계값은 모두 **제안**이다. 379 기존 맵 재현에 근거하며 신규 맵 정확도를 보장하지 않는다(§7-2).
- **분리 시드 확인의 한계**: C 재측정은 "같은 맵의 봇 측정이 시드 운에 흔들리지 않는가"(봇 측정 안정성)만 확인한다. 모델 편향(§2-3)은 S와 C에 똑같이 들어 있으므로 **실유저 신규 맵 독립 검증을 대신하지 않는다.**
- 선택 편향 점검(31 §4-3): S→C 평균 예측 감소 >1%p면 선별 압력 과다 경보, 선택 후보 OOD 점수 분포 vs 전체 후보 비교.
- 시드 대역(**정정**): 이전 판의 S = 13.0M대 제안은 자연실험(`natural_experiment.py:279`, 13,000,000 + li·1000 + g, 26 §11-7)과 겹친다. 사용 중 = 학습 11.0M대, 자연실험 13.0M대, DDA 7.6M·7.8M·(제안)8.2M. **S = 15.0M대, C = 16.0M대**로 바꿔 제안(착수 전 스크립트 전수 grep으로 재확인).

### 3-5. 예측 분포 넓히기 후처리 — 기본 금지
- E1 예측 sd가 실제의 57%(34)라서 분포를 실제처럼 넓히고 싶어질 수 있다. **기본 적용하지 않는다.** 순위 신호가 약한 곳에서 폭만 넓히면 개별 맵 오차가 커지고, 과대예측된 맵을 다시 끌어내린다는 보장도 없다.

## 4. 측정 맵 = 실제 실행 맵 (이전 판 유지, 상태만 갱신)

### 4-2. 설계
- 측정·예측은 최종 조건 함수 출력만 입력으로 받는다(`8af7ebd`에 구현됨). 표시·판정 시 해시 재계산 → 다르면 `stale`(§3-2 무효화).
- D16(업로드 후처리 일원화)과의 관계: 측정 쪽이 업로드 규칙을 **미러**하고 테스트로 묶는다. 프론트 업로드가 그 함수를 호출하도록 바꾸는 것(D16 본체)·표시 난이도(D15)는 **별도 승인**.

## 7. 검증 기준 (F)

### 7-1. 지표 (⑤ 기준, 레벨 단위. 구간은 **실측 기준** <0.85 / 0.85~0.92 / 0.92~0.96 / ≥0.96 과 **예측·목표 기준** 같은 구간을 둘 다 보고)
| 지표 | 정의 | 주의 |
|---|---|---|
| 구간별 MAE·편향 | 예측 − 실측 | 실측 기준 구간은 위험 크기, 예측·목표 기준 구간은 운영 시 쓸 수 있는 편향표. 천장 구간 MAE는 작게 보임 |
| 잔차 기울기 | (예측−실측) ~ 실측 | 현재 −0.57(35a). 0에 가까워지는지가 쏠림 개선의 직접 지표 |
| 순위상관 ρ | 구간 안 Spearman | 변별력의 주 지표 |
| 목표 적중률 | 실측이 목표 ±5%p / ±10%p / logit ±0.7 안 | 무작위 선택 기준선과 함께 |
| 예측 구간 포함률 | 실측이 80% 범위 안 | 목표 0.75~0.85, 실측 잡음 포함 기대치와 비교 |
| 보정 기울기 | logit 실측 ~ logit 예측 | 1에서 크게 벗어나면 재학습 |
| 승자의 저주 | 선택 맵 실측 − 확인(C) 예측 평균 | 재현 예상 −1~−3%p, 낮은 목표에서 더 큼 |
| 레벨셋 곡선 패턴 | 레벨 번호 x축 목표·예측·실측 곡선; 구간별 평균 차, 어려운 레벨(계단) 위치 일치율 | 시각 + 수치 |
| 판정 분포 | 합격·불합격·근거 부족 비율, 근거 부족 사유별 | 근거 부족이 많으면 지원 범위 부족 신호 |
| 표본·불확실성 | 레벨별 n·Wilson CI, 레벨 묶음 bootstrap CI | n<100 레벨은 레벨 단위 지표에서 제외·별도 표기. 저성공 레벨은 도움 효과 폭이 커(35a) CI가 더 넓다 |

### 7-3. 맵 그룹 정의 (이전 판 유지)
- 구조 해시(층·좌표·효과·컨테이너, 타일 타입 배정 제외). 근거: 샤드 vs LIVE3 불일치 34 중 33이 타입 배정만 다름(29 §2-1).

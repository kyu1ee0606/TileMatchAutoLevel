# 템플릿 기반 창의적 모양 생성 (설계)

> 상태: **1차 구현 완료**. 선행 커밋 `9de3b07`(예쁜 모양 자동개선) 위에 추가.
> 구현됨: 로더·회전/반전 변형·리스케일 폴백·중앙정렬·혼합비율·게이트면제. 검증 통과.
> 2차 보류: 대칭 perturbation(§4-3), disabled 패턴 제외(§7), 재조합(§4-3).

## 1. 배경 / 문제
현재 `pattern_synth.synthesize_concepts`는 **추상 모티프(알파벳/기호) + 기하 전략**으로 맨바닥부터 모양 생성.
→ 사람이 만든 좋은 템플릿 라이브러리(`custom_patterns.json`, 인덱스 0~63)를 **전혀 활용 안 함**.
→ 결과가 가끔 애매. 시작점이 추상적이라 완성도 한계.

## 2. 핵심 아이디어
**이미 검증된 손제작 템플릿을 씨앗으로 변형** → 손맛 보존 + 다양성↑. 새 뱅크 설계 불필요(뱅크 존재).

## 3. 확보한 사실 (custom_patterns.json)
- 포맷: `{ "<idx>_<size>": {grid_size, positions:["x_y"...]} }`
- 인덱스 0~63 (61개), 265 변형
- 사이즈 분포: 4x4:49, 5x5:42, 6x6:57, 7x7:50, 8x8:52, 9x9:15
- **타깃 4~7 풀커버 인덱스: 34개** → 리스케일 없이 기존 변형 직접 사용 가능
- ÷3: 253/265 통과. 위반 3건(`21_5x5`,`32_5x5`,`46_7x7`) → 로드 시 `_enforce_div3`로 보정
- 비활성 패턴은 `pattern_config.disabled_patterns`로 별도 관리(존중 필요)

## 4. 설계: 신규 전략 `template`

### 4-1. 로더 (신규 `_load_templates()`)
- `custom_patterns.json` 읽어 `{idx: {size: set(cells)}}` 캐시(1회).
- ÷3 위반 변형은 로드 시 `_enforce_div3` 보정.
- disabled 인덱스 제외(선택).

### 4-2. 컨셉 생성 (template 전략)
한 컨셉 = (인덱스 1개 + 변형파라미터) 고정 → 타깃 사이즈 전체 렌더:
- 풀커버 인덱스: 기존 size 변형 직접 사용
- 미보유 size: 보유 최근접 size에서 **0~1 정규화 후 재래스터**(`_make_motif`의 polygon 방식 재사용) → ÷3 보정

### 4-3. 창의적 변형 (base 1개 → 변종 다수)
모든 사이즈에 **동일 변형** 적용(번들 일관성):
- 회전 rot∈{0,1,2,3} · 반전 flip — `_tf_pt` 재사용(좌표 정규화 변환)
- 대칭 perturbation: 일부 셀을 orbit 단위 추가/제거(±3 유지) → 변주하되 대칭·÷3 보존
- (선택) 재조합: 두 템플릿 교집합/합집합 후 정리 — 2차

### 4-4. 검증/선택 (기존 재사용)
- 생성 셀 → `_score`(대칭·clean·solidity…) + **품질 게이트**(단일홀0·가시컷·min_quality) 그대로 통과
- family 키 = `tpl:<idx>` → 라운드로빈 선택에 자연 편입(인덱스별 골고루)
- 컨셉 dedup(시그니처) + Jaccard 유사도 컷 그대로

### 4-5. 혼합 비율 (auto, pretty)
```
template 50% (주력, 손맛) + motif 20% (대칭화) + 기하전략 30%
```
→ 템플릿 기반을 주력으로, 모티프/기하는 다양성 보조.

## 5. 불변식 (절대 보존)
- ÷3: 모든 변형 후 `_enforce_div3(_symmetric)` 재보정
- custom_patterns.json **읽기 전용** (생성기는 변형 결과를 새 인덱스로만 저장)
- 기존 모티프/기하 경로 무변경 (회귀 방지)
- `pretty=False` 하위호환 유지

## 6. 구현 단계 (verify 포함)
1. `_load_templates()` + 캐시 → verify: 61 인덱스 로드, ÷3 보정 후 전부 통과
2. `_template_concept(idx, rot, flip, sizes)` → verify: 풀커버 인덱스 4~7 셀 반환, ÷3 OK
3. 미보유 size 리스케일 → verify: 부분커버 인덱스도 4~7 완성
4. `synthesize_concepts`에 template 전략 + 혼합비율 추가 → verify: 시드별 다양 + 게이트 통과 + count 충족
5. 대칭 perturbation 변형 → verify: 같은 idx에서 변종 다수, Jaccard 분산
6. 라이브 API + Playwright UI(수동/자동) + tsc + 레벨생성 회귀

## 7. 리스크 / 판단
- 리스케일 화질: 작은 size(4x4)로 줄일 때 디테일 뭉개짐 → 풀커버 인덱스 우선, 리스케일은 폴백
- disabled 패턴 존중: 비활성 인덱스 기반 변형이 활성 라이브러리로 새 저장되면 의도 충돌 → 로드 시 제외 옵션
- 추상 모티프 대비 **결과 품질 상향 기대**(시작점이 사람 검증됨)

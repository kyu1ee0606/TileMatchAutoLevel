## 형식 (정본 §V2-9-2 그대로)
- 행 `seedvar_N` = 원래 `level_N` 행 복사 + `map` = t0화 사본 + `randSeed` 토큰 + `useTileCount` = utc0. 원래 `level_N`은 무변경(대조군).
- 토큰: 5단계 `e2|e1|h1|h2`, 3단계 `e2|h2`. 각 칸은 `seed` 또는 `seed@utc`.
- 3단계 행에서 클라이언트 사다리: s=−1 → e2, s=+1 → 기본(b).

## 크기 기준 (제안값, 사용자 확정 전)
- 바깥 e2/h2: 원맵 대비 봇 가중 성공률 |Δ| ≥ 0.10, 신뢰구간·견고성 통과. h2는 예측 클리어% ≥ 원맵의 0.5배 + 최고 실력점 성공률 ≥ 0.10 + 해법 증거.
- 안쪽 e1/h1: Δ ≥ 0.04, 저스킬 점 포함 견고성 + 같은 쪽 서열 과반. 실패 시 3단계.
- Δ는 봇 기준 상대 지표다. 사람 클리어율이 아니다.
